# ⛅ AeroWeather 3D — Real-Time Weather Application

**AeroWeather 3D** é uma aplicação web moderna de previsão do tempo que combina dados meteorológicos em tempo real com um plano de fundo dinâmico e interativo renderizado em **3D via Three.js (WebGL)**[span_0](start_span)[span_0](end_span). O projeto conta com design responsivo focando em alta performance e experiência do usuário no mobile e desktop[span_1](start_span)[span_1](end_span).

---

### ✨ Funcionalidades

* 🌐 **Geolocalização & Busca Dinâmica:** Identificação automática da cidade do usuário e campo de pesquisa instantâneo.
* 🌌 **Background 3D Interativo:** Efeitos visuais em partículas e objetos 3D imersivos usando Three.js[span_2](start_span)[span_2](end_span).
* 🔔 **Módulo de Alertas em Tempo Real:** Conexão direta via integração WhatsApp para notificações urgentes de tempestade.
* 📱 **Design Mobile-First:** Interface fluida, responsiva e com suporte a interações por toque[span_3](start_span)[span_3](end_span).
* 🎯 **Identidade Corporativa:** Assinaturas estruturadas e personalizadas do **Grupo Nascimento**.

---

### 🛠️ Tecnologias Utilizadas

* **HTML5:** Estrutura semântica e otimizada para SEO.
* **CSS3:** Estilização moderna em modo escuro (*Dark Mode*), suporte a *Glassmorphism* e *Flexbox/Grid*.
* **JavaScript (Vanilla JS):** Manipulação eficiente do DOM e requisições assíncronas.
* **Three.js (WebGL):** Renderização de elementos gráficos 3D no navegador com foco em performance.
